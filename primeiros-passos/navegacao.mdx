# Navegação no FLUP

O FLUP possui uma barra lateral (menu) à esquerda da tela que permite acessar todos os módulos do sistema.

## Menu Lateral

O menu lateral contém links para todas as principais funcionalidades do sistema:

- **Dashboard**: Visão geral do negócio
- **Orçamentos**: Criação e gerenciamento de orçamentos
- **Pedidos**: Gerenciamento de pedidos de clientes
- **Clientes**: Cadastro de clientes
- **Produtos**: Cadastro de produtos e ingredientes
- **Receitas e Precificação**: Montagem de receitas e cálculo de preços
- **Cardápio**: Gerenciamento do cardápio público
- **Estoque**: Controle de estoque de produtos
- **Calendário**: Visualização de agenda
- **Fluxo de Caixa**: Registro de receitas e despesas
- **Relatórios**: Visualização de relatórios
- **Configurações**: Configurações do sistema

## Como navegar

### Clicar no menu
Basta clicar no item desejado no menu lateral para acessar a funcionalidade. O item ativo fica destacado com uma cor diferente.

### Seletor de organização
Se você tiver acesso a mais de uma organização, verá um seletor no canto inferior esquerdo da tela. Clique nele para alternar entre organizações.

### Informações do usuário
No canto inferior esquerdo, você verá seu nome e email. Ao lado, há um botão para fazer logout (sair do sistema).

## Módulos adicionais

Alguns módulos podem aparecer apenas para usuários com permissões específicas:

- **Notificações** (apenas para administradores)
- **Organizações** (apenas para administradores do sistema)

## Gerenciamento da organização

Se você for administrador de uma organização, verá uma seção adicional no menu lateral com:

- **Usuários**: Gerenciar usuários da organização
- **Perfil**: Editar dados da organização

## Dicas de navegação

- O menu lateral fica sempre visível enquanto você estiver logado
- Você pode acessar qualquer módulo a qualquer momento
- O sistema mantém seu lugar na navegação mesmo após atualizar a página
- Use o botão de voltar do navegador para retornar à tela anterior
