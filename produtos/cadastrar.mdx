# Como Cadastrar um Produto

Siga estes passos para cadastrar um novo produto no FLUP.

## Antes de começar

Certifique-se de que você já tem acesso ao sistema e está logado.

## Passo 1 — Acesse Produtos

1. No menu lateral, clique em **Produtos**
2. Você verá a lista de produtos já cadastrados (se houver)

## Passo 2 — Clique em Novo Produto

1. No canto superior direito da tela, clique no botão **Novo Produto**
2. Uma janela será aberta para preencher os dados do produto

## Passo 3 — Preencha os dados do produto

### Nome
- Digite o nome do produto (ex: Farinha de Trigo)
- Este campo é obrigatório

### Marca (opcional)
- Clique no campo de marca
- Selecione uma marca existente ou clique em **+ Nova Marca** para criar
- Se criar uma nova marca, digite o nome e clique em **Criar**

### Local de Compra (opcional)
- Clique no campo de local de compra
- Selecione um local existente ou clique em **+ Novo Local** para criar
- Se criar um novo local, digite o nome e clique em **Criar**

### Informações da Embalagem

#### Tamanho da Embalagem
- Digite a quantidade da embalagem (ex: 5 para 5 kg)
- Este campo é obrigatório
- Use números decimais se necessário (ex: 0.5 para 500g)

#### Unidade da Embalagem
- Selecione a unidade de medida:
  - **kg** - quilograma
  - **g** - grama
  - **L** - litro
  - **ml** - mililitro
  - **un** - unidade
- Este campo é obrigatório

## Passo 4 — Salve o produto

1. Clique no botão **Criar**
2. O sistema perguntará se deseja adicionar estoque inicial
3. Clique em **Sim** para adicionar estoque ou **Não** para apenas cadastrar

## Passo 5 — Adicione estoque inicial (opcional)

Se você clicou em **Sim**:

1. Informe a quantidade que você tem em estoque
2. Informe o estoque mínimo (quantidade mínima desejada)
3. Informe o custo da compra (quanto você pagou)
4. Clique em **Confirmar**

## Resultado

O produto será cadastrado e aparecerá na lista de produtos. Se você adicionou estoque inicial, o produto já estará disponível para uso em receitas.

## Dicas

- Use nomes claros e específicos (ex: "Farinha de Trigo Tipo 1" em vez de apenas "Farinha")
- Cadastre marcas que você realmente utiliza para organizar melhor
- Se não souber o custo exato, deixe em branco e preencha depois
- Você pode editar as informações do produto a qualquer momento
