# Como Cadastrar um Cliente

Siga estes passos para cadastrar um novo cliente no FLUP.

## Passo 1 — Acesse Clientes

1. No menu lateral, clique em **Clientes**
2. Você verá a lista de clientes já cadastrados (se houver)

## Passo 2 — Clique em Novo Cliente

1. No canto superior direito da tela, clique no botão **Novo Cliente**
2. Uma janela será aberta para preencher os dados do cliente

## Passo 3 — Preencha os dados do cliente

### Nome
- Digite o nome do cliente ou da empresa
- Este campo é obrigatório

### Telefone
- Digite o telefone para contato
- Este campo é obrigatório
- Use o formato com DDD (ex: (11) 99999-9999)

### Email
- Digite o email do cliente
- Este campo é obrigatório
- Use um email válido

### Endereço
- Digite o endereço completo
- Este campo é obrigatório
- Inclua rua, número, bairro, cidade e estado

### Fonte (opcional)
- Clique no campo de fonte
- Selecione uma fonte existente ou clique em **+ Nova Fonte** para criar
- Se criar uma nova fonte, digite o nome e clique em **Criar**

### Notas (opcional)
- Adicione observações sobre o cliente
- Exemplo: "Prefere entregas pela manhã", "Cliente VIP"

## Passo 4 — Salve o cliente

1. Clique no botão **Criar**
2. O cliente será cadastrado e aparecerá na lista

## Resultado

O cliente será cadastrado com:

- Total de pedidos = 0
- Todas as informações preenchidas
- Disponível para seleção em orçamentos e pedidos

## Dicas

- Cadastre informações completas para facilitar entregas
- Use a fonte para rastrear de onde vieram os clientes
- Adicione notas importantes sobre preferências do cliente
- Mantenha os dados atualizados
