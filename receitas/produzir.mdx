# Como Registrar Produção

Registrar produção é a ação de deduzir ingredientes do estoque e adicionar produtos prontos ao estoque produzido.

## O que é Registrar Produção

Quando você registra a produção de uma receita:

- Os ingredientes são deduzidos do estoque
- O produto pronto é adicionado ao estoque produzido
- O custo de produção é registrado

## Quando registrar produção

Registre produção quando:

- Você acabou de produzir um lote de produtos
- Quer atualizar o estoque de ingredientes
- Quer adicionar produtos prontos ao estoque

## Passo 1 — Acesse Receitas

1. No menu lateral, clique em **Receitas e Precificação**
2. Clique na aba **Estoque Produzido**

## Passo 2 — Clique em Registrar Produção

1. No canto superior direito, clique no botão **Registrar Produção**
2. Uma janela será aberta

## Passo 3 — Selecione a receita

1. Clique no campo de receita
2. Selecione a receita que você produziu
3. O sistema mostrará quanto já está pronto em estoque

## Passo 4 — Informe a quantidade

1. Informe quantos lotes você produziu
2. Exemplo: se produziu 2 vezes a receita, informe 2

## Passo 5 — Adicione observações (opcional)

1. Se desejar, adicione notas sobre a produção
2. Exemplo: "Produção matinal"

## Passo 6 — Confirme

1. Clique no botão **Registrar**
2. O sistema verificará se há estoque suficiente

## Se houver estoque suficiente

- Os ingredientes são deduzidos
- O produto pronto é adicionado ao estoque
- Você verá uma mensagem de sucesso

## Se não houver estoque suficiente

- O sistema mostrará quais ingredientes faltam
- A produção não será registrada
- Você precis repor os ingredientes primeiro

## Resultado

Após registrar produção:

- O estoque de ingredientes é atualizado
- O estoque produzido da receita é incrementado
- O histórico de produção é salvo

## Dicas

- Registre produção logo após produzir para manter o estoque atualizado
- Verifique o estoque antes de começar a produzir
- Use as observações para rastrear lotes específicos
