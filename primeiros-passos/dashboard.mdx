# Dashboard

O Dashboard é a tela inicial do FLUP após você fazer login. Ele oferece uma visão geral rápida do desempenho do seu negócio com métricas importantes e gráficos.

## O que você encontra no Dashboard

### Métricas principais

No topo da tela, você verá quatro cartões com as principais métricas do mês:

- **Receita Mensal**: Total de receita do mês atual
- **Pedidos do Mês**: Número de pedidos realizados no mês
- **Lucro do Mês**: Lucro líquido (receita menos despesas)
- **Despesas do Mês**: Total de despesas do mês

Cada métrica mostra o valor atual e a comparação com o mês anterior.

### Gráficos

O Dashboard exibe dois gráficos principais:

#### Gráfico de Vendas Semanais
- Mostra as vendas dos últimos 7 dias
- Ajuda a identificar padrões de vendas
- Permite visualizar quais dias têm mais movimento

#### Gráfico de Despesas Semanais
- Mostra as despesas dos últimos 7 dias
- Ajuda a controlar gastos
- Permite identificar picos de despesas

### Listas informativas

#### Produtos Mais Vendidos
- Lista os produtos com maior volume de vendas
- Mostra a quantidade vendida de cada produto
- Ajuda a identificar os itens mais populares

#### Pedidos Recentes
- Mostra os pedidos mais recentes
- Exibe o nome do cliente, data, status e valor
- Permite acesso rápido aos pedidos

#### Próximas Datas Comerciais
- Exibe datas importantes para o negócio (ex: Dia das Mães, Natal)
- Mostra quando cada data ocorrerá
- Ajuda no planejamento de produção e estoque

## Botão de Novo Pedido

No canto inferior direito da tela, você verá um botão flutuante com o símbolo **+**. Este botão permite criar rapidamente um novo pedido sem precisar navegar para a tela de Pedidos.

## Como usar o Dashboard

1. **Acompanhe diariamente**: Verifique as métricas e gráficos para entender o desempenho do seu negócio
2. **Identifique tendências**: Use os gráficos para identificar padrões de vendas e despesas
3. **Acesse pedidos rapidamente**: Clique em qualquer pedido recente para ver detalhes
4. **Crie pedidos**: Use o botão flutuante para criar pedidos rapidamente

## Dicas

- As métricas são atualizadas automaticamente quando novos dados são adicionados
- Os gráficos mostram apenas os últimos 7 dias para manter a visão atualizada
- Se não houver dados suficientes, os gráficos podem aparecer vazios
- Clique nos cartões ou listas para navegar para as telas correspondentes
