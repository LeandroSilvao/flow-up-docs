# Como Movimentar Estoque

Movimentar estoque é adicionar ou remover produtos do seu estoque.

## Tipos de movimentação

- **Entrada (IN)**: Adicionar estoque (compra, reposição)
- **Saída (OUT)**: Remover estoque (produção, desperdício)

## Passo 1 — Acesse Estoque

1. No menu lateral, clique em **Estoque**
2. Você verá a lista de produtos com seus estoques

## Passo 2 — Encontre o produto

1. Use a busca para encontrar o produto
2. Ou use os filtros para encontrar produtos específicos

## Passo 3 — Clique no botão de movimentação

### Para adicionar estoque (entrada)

1. Na linha do produto, clique no botão **+** (verde)
2. Uma janela será aberta

### Para remover estoque (saída)

1. Na linha do produto, clique no botão **-** (vermelho)
2. Uma janela será aberta

## Passo 4 — Preencha a movimentação

### Produto

O produto já estará selecionado. Você pode mudar se necessário.

### Quantidade

1. Informe a quantidade a movimentar
2. Use números decimais se necessário
3. Este campo é obrigatório

### Motivo

1. Selecione o motivo da movimentação:
   - **Compra**: Para entradas por compra
   - **Produção**: Para saídas por produção
   - **Ajuste**: Para ajustes manuais
   - **Desperdício**: Para perdas
   - **Outros**: Para outros motivos

### Observações (opcional)

1. Adicione notas se necessário
2. Exemplo: "Compra Atacadão", "Produção matinal"

## Passo 5 — Confirme

1. Clique no botão **Confirmar**
2. O estoque será atualizado imediatamente

## Resultado

Após movimentar:

- O estoque do produto é atualizado
- Uma movimentação é registrada no histórico
- O valor do estoque é recalculado

## Ver detalhes da movimentação

Para ver o histórico de movimentações:

1. Na linha do produto, clique no ícone de olho (👁️)
2. Uma janela mostrará todas as movimentações
3. Você pode filtrar por data e tipo

## Dicas

- Movimente estoque logo após comprar ou usar produtos
- Use observações para rastrear a origem das movimentações
- Verifique o histórico regularmente para identificar padrões
- Use ajustes apenas quando necessário
