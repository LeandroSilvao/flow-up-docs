# Acesso ao Sistema

Para começar a usar o FLUP, você precisa fazer login no sistema.

## Como fazer login

1. Abra o navegador e acesse o endereço do FLUP fornecido pela sua organização
2. Você verá a tela de login
3. Digite seu **email** no campo "Email"
4. Digite sua **senha** no campo "Senha"
5. Clique no botão **Entrar**

## Campos obrigatórios

- **Email**: Campo obrigatório, deve ser um email válido cadastrado no sistema
- **Senha**: Campo obrigatório, deve ser a senha cadastrada para seu usuário

## Problemas comuns

### Email ou senha incorretos
Se o email ou senha estiverem incorretos, o sistema exibirá uma mensagem de erro. Verifique:
- Se está digitando o email corretamente
- Se a tecla Caps Lock está ativada
- Se está usando a senha correta

### Usuário inativo
Se seu usuário estiver inativo, o login não será permitido. Entre em contato com o administrador da sua organização para reativar seu acesso.

### Esqueceu a senha
Se você esqueceu sua senha, entre em contato com o administrador da sua organização. Ele poderá redefinir sua senha.

## Após o login

Após fazer login com sucesso:

- Você será redirecionado automaticamente para o **Dashboard**
- O sistema carregará os dados da sua organização
- Você poderá acessar todos os módulos disponíveis para seu perfil

## Primeiro acesso

Se é seu primeiro acesso ao ORBIT:

1. Verifique se recebeu um email de boas-vindas com suas credenciais
2. Se não recebeu, entre em contato com o administrador
3. Ao fazer o primeiro login, recomendamos alterar sua senha
4. Explore o Dashboard para familiarizar-se com o sistema

## Segurança

- Nunca compartilhe sua senha com outras pessoas
- Use uma senha forte com letras, números e caracteres especiais
- Faça logout ao terminar de usar o sistema, especialmente em computadores compartilhados
- Altere sua senha periodicamente

## Logout

Para sair do sistema:

1. Clique no seu nome no canto inferior esquerdo da tela
2. Clique no ícone de logout (sair)
3. Você será redirecionado para a tela de login

## Múltiplas organizações

Se você tiver acesso a mais de uma organização:

- Após o login, você poderá selecionar qual organização deseja usar
- Use o seletor de organização no canto inferior esquerdo para alternar
- Cada organização tem seus dados separados
