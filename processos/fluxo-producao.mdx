# Fluxo de Produção

Este guia mostra como registrar produção de receitas e gerenciar o estoque de produtos prontos.

## Visão geral do fluxo

```
Verificar ingredientes → Produzir → Registrar → Deduzir estoque → Adicionar produtos prontos
```

## Passo 1 — Verificar ingredientes

1. Acesse **Estoque**
2. Verifique se há quantidade suficiente de todos os ingredientes
3. Se faltar algum, registre a entrada (veja [Fluxo de Compra](/processos/fluxo-compra))

## Passo 2 — Produzir

1. Produza o produto seguindo sua receita
2. Anote quantas vezes produziu a receita
3. Anote qualquer observação (ex: "Lote matinal")

## Passo 3 — Registrar produção

1. Acesse **Receitas e Precificação**
2. Clique na aba **Estoque Produzido**
3. Clique em **Registrar Produção**
4. Selecione a receita que produziu
5. Informe a quantidade (número de vezes que produziu a receita)
6. Adicione observações se necessário
7. Clique em **Registrar**

<Callout type="warning">
  O sistema verificará se há estoque suficiente de ingredientes. Se não houver, a produção não será registrada.
</Callout>

## Passo 4 — Verificar resultado

Após registrar:

- O estoque de ingredientes é deduzido automaticamente
- O estoque de produtos prontos é incrementado
- Você verá a nova quantidade na aba "Estoque Produzido"

## Passo 5 — Ajustar se necessário

Se precisar ajustar o estoque produzido:

1. Na aba "Estoque Produzido", encontre a receita
2. Clique no ícone de ajuste (⚙️)
3. Informe a quantidade correta
4. Clique em **Salvar**

<Callout type="info">
  Use ajustes apenas quando necessário para corrigir erros ou perdas não planejadas.
</Callout>

## Produção a partir de pedido

Quando um pedido é movido para "Em Produção":

- O sistema verifica se há estoque de produtos prontos
- Se houver: deduz do estoque de produtos prontos
- Se não houver: mostra alerta informando que precisa registrar produção

## Resumo

| Etapa | O que fazer | Onde |
|-------|-------------|------|
| Verificar ingredientes | Verificar estoque | Estoque |
| Produzir | Produzir o produto | Externo |
| Registrar produção | Registrar no sistema | Receitas/Estoque Produzido |
| Verificar resultado | Confirmar estoques | Receitas/Estoque Produzido |
| Ajustar | Corrigir se necessário | Receitas/Estoque Produzido |

## Dicas

- Registre produção logo após produzir para manter o estoque atualizado
- Verifique o estoque de ingredientes antes de começar a produzir
- Use observações para rastrear lotes específicos
- Ajuste o estoque apenas quando necessário
